# Dingent clone traffic archive

**726 archived clones** across 14 recorded UTC dates (2026-10-31 through 2026-11-13).

Daily data: [JSON](clones.json) · [CSV](clones.csv) · [Badge](clones.svg).

Counts cover only the dates collected here, not the entire lifetime of the repository. Missing dates are unknown, not zero. Each date keeps the highest count observed, so overlapping API windows and partial boundary days do not erase previously collected counts. The latest day may still be incomplete. Daily uniques are provided for each date; their sum is not the number of distinct people across dates.

See [setup and methodology](https://github.com/Dingent/Dingent/blob/main/docs/clone-traffic.md).
